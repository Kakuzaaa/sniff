## 📦 Установка

> [!NOTE]
> Это юзерскрипт — нужен загрузчик: **[Tampermonkey](https://www.tampermonkey.net/)** (Chrome, Edge, Firefox) или **[Violentmonkey](https://violentmonkey.github.io/)** (хороший выбор для Opera).

### Способ 1 — в один клик (рекомендуется)

1. Установите загрузчик юзерскриптов (ссылки выше)
2. Откройте **[ссылку установки](https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.14/domain-sniffer-pro.user.js)** — менеджер сам предложит установить скрипт
3. Подтвердите запрос доступа ко всем сайтам (нужен для перехвата запросов сайта и живых проверок блокировок)

> Ссылка ведёт на зафиксированный релиз-тег `v4.14` — CDN jsDelivr доступнее в РФ, чем GitHub raw, и у тега нет кэш-задержки. Обновления приходят автоматически — [подробнее](#-обновления).

### Способ 2 — из GitHub Releases

1. Откройте **[Releases](https://github.com/Kakuzaaa/sniff/releases/latest)** и скачайте `domain-sniffer-pro.user.js`
2. Откройте скачанный файл в браузере (или перетащите его на страницу Tampermonkey → «Утилиты» → «Импорт из файла»)
3. Подтвердите установку

> [!WARNING]
> **Tampermonkey 5.2+ на Chromium** (Chrome / Edge / Brave / Vivaldi): может понадобиться
> 1. включить «Режим разработчика» на странице `chrome://extensions` ([справка Tampermonkey](https://www.tampermonkey.net/faq.php#Q209));
> 2. при Chromium 138+ — в «Сведениях» расширения включить «Разрешить пользовательские скрипты».

### Способ 3 — ручная установка (всегда работает)

1. Откройте [файл скрипта](https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.14/domain-sniffer-pro.user.js) и скопируйте всё (`Ctrl+A` → `Ctrl+C`)
2. Иконка Tampermonkey → «Юзерскрипты» → вкладка «+» → вставьте (`Ctrl+V`) → сохраните (`Ctrl+S`)

### Способ 4 — импорт по URL

Иконка Tampermonkey → **«Утилиты»** → «Импорт из URL» → вставьте:

```
https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.14/domain-sniffer-pro.user.js
```

→ «Установить».

### Если установка не сработала

Страница Tampermonkey «Script installation» висит без диалога установки? Так бывает, когда расширение не смогло скачать файл — в РФ `raw.githubusercontent.com` часто режется провайдером, а VPN-расширение в браузере может не покрывать запросы самого Tampermonkey. Основные ссылки тут идут через jsDelivr, но если и он подводит:

- включите в настройках Tampermonkey режим «Дополнительно» и «Мгновенная установка» (Instant installation) — промежуточная страница перестанет открываться, диалог появится сразу;
- попробуйте прямую ссылку GitHub: [raw…/domain-sniffer-pro.user.js](https://raw.githubusercontent.com/Kakuzaaa/sniff/main/domain-sniffer-pro.user.js);
- сброс кэша jsDelivr: [purge-инструмент](https://www.jsdelivr.com/tools/purge) + URL `https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@main/domain-sniffer-pro.user.js`;
- крайний случай — [способ 3](#способ-3--ручная-установка-всегда-работает), он не зависит ни от чего.

## ✨ Возможности

### 1. Сбор доменов (с 0-й миллисекунды)
- перехват `fetch` / `XHR` / `WebSocket` / `SSE` / `sendBeacon` / `WebRTC (STUN/TURN)`;
- сетевой буфер браузера (PerformanceObserver) — даже неудачные запросы;
- скан DOM и CSS (`src`, `href`, `srcset`, `url()`, `@import`, `<style>`) — собранные так **домены-ссылки** (страница их не загружала, они просто стоят ссылками: результаты поиска, футеры, README) по умолчанию скрыты; чип **«Только трафик»** переключает — приглушённые строки с бейджем «ссылка» показываются внизу списка;
- домены из встроенных iframe (плееры, капча) пересылаются в родительскую страницу;
- список накапливается при переходах по сайту.

### 2. Детектор блокировок (кнопка «Проверить»)
| Бейдж | Что значит |
|---|---|
| ● OK | доступен |
| ● DPI | сброс соединения — похоже на DPI-блокировку по имени домена (SNI) |
| ● IP | нет ответа — похоже на полную блокировку по IP |
| ● 16-20КБ | «заморозка»: провайдер обрывает передачу после ~16-20 КБ |
| ● обрыв / ● медленно | соединение оборвалось / сильное замедление |
| ● стаб-страница | провайдер отдаёт заглушку вместо сайта |

- IP домена резолвится через DNS-over-HTTPS и сверяется с заблокированными подсетями — так видны блоки хостингов (Hetzner, Cloudflare и т.п.);
- «заморозка 16-20КБ» **подтверждается POST-тестом**: 64 КБ данных на живой хост — если передача обрезается, это факт, а не эвристика;
- «стаб-страница»: маленький ответ 200 с маркерами «ограничен доступ» — провайдер подменяет сайт заглушкой;
- перед проверкой пингуются контрольные точки (ya.ru, vk.com, sberbank.com) — если они не отвечают, панель предупредит, что результаты могут быть недостоверны;
- тип блокировки определяется по фактическому поведению **вашего** провайдера — это эвристика, реестр способ не публикует.

### 3. Маршрут каждого домена (⚙ — Clash API)
- подключается к **Clash API** вашего роутера (Podkop / Forkop / NetShift — дашборд YACD, порт 9090) или локального ядра (sing-box / clash / v2rayN);
- показывает для каждого домена: **через прокси** (какую цепочку) или **напрямую** (по какому правилу);
- красное **«заблокирован и НЕ в прокси»** — домен блокируется, но в прокси-лист роутера не попал: **вот почему сайт не работает**;
- без Clash API — косвенные признаки со знаком «?» (реестр + доступность + задержка), общий статус сплит-маршрутизации.

### 4. Регион-чек по РФ (кнопка «Регионы» / иконка глобуса на строке)
- через открытый API [cheburcheck.ru](https://cheburcheck.ru): десятки сканеров в регионах России проверяют домен и присылают вердикты (SNI-блок, ТСПУ-блок, подмена DNS, CDN-блок 16-20КБ);
- видно, блокировка **общая** (`SNI-блок 28/35 рег.`) или **только у вашего оператора**;
- скан занимает ~1-2 минуты, кэш 6 часов, проверки идут по одной.

### 5. Интерфейс — Liquid Glass
- стеклянная панель 640px с блюром поверх сайта, тёмная/светлая/авто-тема (кнопка с полукругом в шапке);
- статусы — цветные точки с подписями (● OK, ● DPI, ● IP, ● 16-20КБ, ● медленно, ● стаб-страница) вместо эмодзи;
- шапку можно тащить мышью; по умолчанию панель всегда открывается справа снизу, а «Запоминать перетаскивание» включается в ⚙ — и в любом случае панель вписывается в экран;
- настройки интерфейса в ⚙: автоскрытие в полноэкранном режиме (видео, F11), прозрачность кнопки и панели в покое, хоткей **Alt+Shift+D** — скрыть/показать;
- клик по имени домена или иконке копирования — скопировать один домен;
- живой поиск по списку + позиция прокрутки сохраняется при обновлениях;
- встроенная справка по кнопке «?».

### 6. Шумодавы (в шестерёнке ⚙)
- **Игнор-лист с масками**: `*.doubleclick.net`, `ads.*`, `*betting*` — домены по маскам не собираются вовсе (одна маска в строке, `*` — любой кусок имени, маска без `*` ловит домен и все его поддомены);
- **Режим сбора ссылок**: все / только внутренние (свой корневой домен) / не собирать — управляет тем, попадают ли в список домены, которые страница не загружала, а просто упоминала;
- **Кнопка «Проблемные»**: копирует только заблокированные и «не в прокси» домены — готовый список для вставки в прокси-лист Podkop/NetShift.

### 7. Точность диагностики
- **Кнопка «Доступность хостингов»**: POST 64 КБ на 5 популярных зарубежных хостингов (Cloudflare, AWS, Fastly, DigitalOcean, Contabo) — проверяет, обрывает ли провайдер передачу («заморозка 16-20КБ»); вердикт с детализацией по каждой подсети показывается в карточке и не исчезает;
- **Карточка результатов**: вердикты тестов и предупреждения показываются под списком в заметной рамке и не исчезают сами (закрываются крестиком);
- **Детектор заглушек**: маленький ответ с маркерами «ограничен доступ» = бейдж «стаб-страница», а не «доступен»;
- **Контрольные точки**: ya.ru / vk.com / sberbank.com проверяются перед массовой проверкой — если они не отвечают, результаты помечаются как недостоверные.

## 🚀 Быстрый старт

1. Откройте интересующий сайт — домены собираются автоматически, счётчик виден в правом нижнем углу.
2. Нажмите «Проверить» — панель покажет статусы блокировок у вашего провайдера (первый раз скачает реестр ~10-20 МБ, кэш 12 ч).
3. Хотите понять «почему не работает»: подключите Clash API роутера через шестерёнку в шапке → красные строки «не в прокси» покажут, какие домены надо добавить в прокси-лист.
4. «Регионы» — проверить домен по всем операторам РФ.
5. Клик по имени домена в списке (или иконке копирования) — скопировать этот домен отдельно; клик по остальной строке — перепроверить его.
6. «?» в панели — встроенная справка по всем статусам и кнопкам.

## 🔄 Обновления

- **Автоматически**: Tampermonkey раз в сутки проверяет `@updateURL` (jsDelivr `@main`) — новая версия появляется в течение ~12 часов после релиза; интервал проверки настраивается в настройках Tampermonkey.
- **Вручную**: дашборд → «Юзерскрипты» → кнопка «Проверить обновления»; или откройте настройки скрипта → «Проверить обновления скриптов».
- Текущая версия — в колонке «Версия» дашборда или в шапке файла (`@version`); актуальная — на странице [последнего релиза](https://github.com/Kakuzaaa/sniff/releases/latest).
- Если «Обновлений не найдено», а релиз уже вышел — это кэш CDN: откройте [purge-ссылку](https://purge.jsdelivr.net/gh/Kakuzaaa/sniff@main/domain-sniffer-pro.user.js) и повторите проверку.

## 🔒 Приватность

- Всё выполняется локально в браузере; список доменов никуда не отправляется;
- живые пробы к проверяемым доменам отправляются **только по кнопке**, без cookies (`anonymous`);
- «Доступность хостингов» и POST-подтверждение отправляют 64 КБ **случайных** данных на проверяемые хостинги (только по кнопке);
- регион-чек — запросы к публичному API cheburcheck.ru (только имя проверяемого домена);
- токен/секрет Clash API хранится локально в хранилище менеджера скриптов.

## ⚠️ Ограничения и честные оговорки

- Тип блокировки — эвристика: «сбой соединения» иногда выглядит как блокировка (поэтому сверяется реестр + проба + регион-чек);
- поточечный маршрут возможен только при включённом Clash API; чистый WireGuard/Amnezia без API из браузера не определить;
- домены в Web Workers не перехватываются (userscript в воркеры не инжектится);
- ТСПУ может душить только крупные ресурсы (видео/файлы) — проба к корню сайта этого не видит.
