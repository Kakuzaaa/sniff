# 🌐 Domain Sniffer Pro

Userscript для **Tampermonkey / Violentmonkey**: собирает все домены и поддомены, которые загружает сайт, определяет, **какие из них заблокированы** (и каким способом), показывает, **кто идёт через прокси, а кто напрямую**, и умеет проверять блокировки **по регионам РФ**.

---

## 📦 Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Firefox) или [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте ссылку на скрипт (CDN jsDelivr — доступнее в РФ, чем GitHub raw) — менеджер предложит установить:
   **[Установить Domain Sniffer Pro v4.1](https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.1/domain-sniffer-pro.user.js)**

   > Ссылка ведёт на зафиксированный релиз-тег `v3.7` — она всегда отдаёт именно эту версию, без CDN-кэша. Обновления прилетают автоматически (проверка раз в сутки, до 12 ч задержка после пуша).
3. При установке подтвердите запрос доступа ко всем сайтам (он нужен для перехвата запросов сайта и живых проверок блокировок).
4. Обновления приходят автоматически — скрипт тянется с CDN этого репозитория.

### Если установка не сработала

Открылась страница Tampermonkey «Script installation», а диалог установки не появился? Так бывает, когда расширение не смогло скачать файл (raw.githubusercontent.com в РФ часто режется провайдером, а VPN-расширение в браузере может не покрывать запросы самого Tampermonkey). Способы обойти:

1. **Ручная установка (всегда работает):** откройте [файл скрипта](https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.1/domain-sniffer-pro.user.js) → выделите всё (`Ctrl+A`) → скопируйте (`Ctrl+C`) → иконка Tampermonkey → «Юзерскрипты» → вкладка «+» → вставить (`Ctrl+V`) → `Ctrl+S` (Файл → Сохранить).
2. **Импорт по ссылке:** иконка Tampermonkey → «Утилиты» → «Импорт из URL» → вставьте `https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@v4.1/domain-sniffer-pro.user.js` → «Установить».
3. **Классическая ссылка GitHub:** [raw.githubusercontent.com/…/domain-sniffer-pro.user.js](https://raw.githubusercontent.com/Kakuzaaa/sniff/main/domain-sniffer-pro.user.js) — сработает, если GitHub raw у вас не заблокирован.
4. Если Tampermonkey показывает бесконечную промежуточную страницу: в настройках Tampermonkey включите режим конфигурации «Дополнительно» и включите «Мгновенная установка» (Instant installation) — промежуточная страница перестанет открываться, диалог будет появляться сразу.
5. Если CDN тормозит со свежими правками: сброс кэша jsDelivr — [purge-инструмент](https://www.jsdelivr.com/tools/purge), вставьте `https://cdn.jsdelivr.net/gh/Kakuzaaa/sniff@main/domain-sniffer-pro.user.js`.

## ✨ Возможности

### 1. Сбор доменов (с 0-й миллисекунды)
- перехват `fetch` / `XHR` / `WebSocket` / `SSE` / `sendBeacon` / `WebRTC (STUN/TURN)`;
- сетевой буфер браузера (PerformanceObserver) — даже неудачные запросы;
- скан DOM и CSS (`src`, `href`, `srcset`, `url()`, `@import`, `<style>`) — собранные так **домены-ссылки** (страница их не загружала, они просто стоят ссылками: результаты поиска, футеры, README) по умолчанию скрыты; чип **«Только трафик»** переключает — приглушённые строки с бейджем «ссылка» показываются внизу списка;
- домены из встроенных iframe (плееры, капча) пересылаются в родительскую страницу;
- список накапливается при переходах по сайту.

### 2. Детектор блокировок (кнопка «🚫 Проверить»)
| Метка | Что значит |
|---|---|
| ✅ | доступен |
| ⛔ | сброс соединения — похоже на DPI-блокировку по имени домена (SNI) |
| 🕳 | нет ответа — похоже на полную блокировку по IP |
| ✂️ | обрыв после ~16-20КБ — «частичная» блокировка страницы |
| 🐢 | очень медленно — похоже на замедление (троттлинг) |
| 📋 / 📍 | домен / его IP-подсеть есть в реестре блокировок (списки antifilter.download) |

- IP домена резолвится через DNS-over-HTTPS и сверяется с заблокированными подсетями — так видны блоки хостингов (Hetzner, Cloudflare и т.п.);
- способ блокировки определяется по фактическому поведению **вашего** провайдера — это эвристика, реестр способ не публикует.

### 3. Маршрут каждого домена (кнопка «⚙»)
- подключается к **Clash API** вашего роутера (Podkop / Forkop / NetShift — дашборд YACD, порт 9090) или локального ядра (sing-box / clash / v2rayN);
- показывает для каждого домена: 🚀 идёт через прокси (какую цепочку) или ⬇ напрямую (по какому правилу);
- 🔴 «заблокирован и НЕ в прокси» — домен блокируется, но в прокси-лист роутера не попал: **вот почему сайт не работает**;
- без Clash API — косвенные признаки: 🚀?/⬇? (реестр + доступность + задержка), общий статус сплит-маршрутизации.

### 4. Регион-чек по РФ (кнопка «Регионы» / иконка глобуса на строке)
- через открытый API [cheburcheck.ru](https://cheburcheck.ru): десятки сканеров в регионах России проверяют домен и присылают вердикты (SNI-блок, ТСПУ-блок, подмена DNS, CDN-блок 16-20КБ);
- видно, блокировка **общая** (`SNI-блок 28/35 рег.`) или **только у вашего оператора**;
- скан занимает ~1-2 минуты, кэш 6 часов, проверки идут по одной.

### 5. Интерфейс — Liquid Glass
- стеклянная панель 640px с блюром поверх сайта, тёмная/светлая/авто-тема (кнопка с полукругом в шапке);
- статусы — цветные точки с подписями (● OK, ● DPI, ● IP, ● 16-20КБ, ● медленно) вместо эмодзи;
- шапку можно тащить мышью — позиция запоминается;
- клик по имени домена или иконке копирования — скопировать один домен;
- встроенная справка по кнопке «?».

### 6. Шумодавы (в шестерёнке ⚙)
- **Игнор-лист с масками**: `*.doubleclick.net`, `ads.*`, `*betting*` — домены по маскам не собираются вовсе (одна маска в строке, `*` — любой кусок имени, маска без `*` ловит домен и все его поддомены);
- **Режим сбора ссылок**: все / только внутренние (свой корневой домен) / не собирать — управляет тем, попадают ли в список домены, которые страница не загружала, а просто упоминала;
- **Кнопка «Проблемные»**: копирует только заблокированные и «не в прокси» домены — готовый список для вставки в прокси-лист Podkop/NetShift.

## 🚀 Быстрый старт

1. Откройте интересующий сайт — домены собираются автоматически, счётчик виден в правом нижнем углу.
2. Нажмите «Проверить» — панель покажет статусы блокировок у вашего провайдера (первый раз скачает реестр ~10-20 МБ, кэш 12 ч).
3. Хотите понять «почему не работает»: подключите Clash API роутера через шестерёнку в шапке → красные строки «не в прокси» покажут, какие домены надо добавить в прокси-лист.
4. «Регионы» — проверить домен по всем операторам РФ.
5. Клик по имени домена в списке (или иконке копирования) — скопировать этот домен отдельно; клик по остальной строке — перепроверить его.
6. «?» в панели — встроенная справка по всем статусам и кнопкам.

## 🔒 Приватность

- Всё выполняется локально в браузере; список доменов никуда не отправляется;
- живые пробы к проверяемым доменам отправляются **только по кнопке**, без cookies (`anonymous`);
- регион-чек — запросы к публичному API cheburcheck.ru (только имя проверяемого домена);
- токен/секрет Clash API хранится локально в хранилище менеджера скриптов.

## ⚠️ Ограничения и честные оговорки

- Тип блокировки — эвристика: «сбой соединения» иногда выглядит как блокировка (поэтому сверяется реестр + проба + регион-чек);
- поточечный маршрут возможен только при включённом Clash API; чистый WireGuard/Amnezia без API из браузера не определить;
- домены в Web Workers не перехватываются (userscript в воркеры не инжектится);
- ТСПУ может душить только крупные ресурсы (видео/файлы) — проба к корню сайта этого не видит.
